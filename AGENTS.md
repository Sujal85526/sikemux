# Repository Instructions

## Git workflow

- Work directly on the `main` branch.
- Do not create or use separate branches.
- Do not create or use Git worktrees.
- Commit all repository changes directly to `main`.
- Make small, atomic commits as work progresses.

## Agent experience

- Do not add agent notifications.
- Launch agents directly into a PTY; do not add an agent prompt/input box or agent worktree controls.
- Open the agent picker modal with `Alt+N` from the agent view.
- Expose only Normal and YOLO agent permission modes.
